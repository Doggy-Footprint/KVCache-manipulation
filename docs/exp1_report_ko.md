# 실험 1 결과 보고서: 프라이밍 / 페르소나가 KV 캐시에 미치는 영향

## 1. 설정
- 모델: Qwen3-0.6B (bf16, MPS). 파이프라인 검증용 모델이며 4B 결과는 아직 없음.
- 데이터: `data/exp1_passages.jsonl`의 시드 지문 5개. 본문은 가장 짧은 지문에 맞춰 246 토큰으로 자름.
- 조건 (모두 prefix 토큰 길이를 맞춰 본문의 절대 위치가 동일):
  - F1, F2: 서로 다른 중립 필러 (위치 통제 및 노이즈 플로어)
  - H+: 올바른 힌트 / H−: 잘못된 힌트
  - P1: 회의적 변호사 페르소나 / P2: 공감적 상담사 페르소나
- 모든 거리는 F1 vs F2 거리(노이즈 플로어)로 나눈 비율로 보고. 헤드별 노름 차이는 F1 본문 벡터의 평균 노름으로 정규화. 분석 대상은 본문 토큰만.
- 분석 1–6 수행. 분석 7(KV 패칭)은 수행하지 않음.

## 2. 검증
- `pytest` 7개 통과.
- 같은 지문(p01)을 다시 돌렸을 때 모든 텐서가 비트 단위로 동일 → 노이즈 플로어는 F1 vs F2 차이만으로 구성.
- 레이어 0의 K/V 거리는 모든 조건에서 정확히 0 (본문 토큰 입력이 같으므로 기대한 결과).

## 3. 결과 (노이즈 플로어 대비 비율)

| 분석 | 결과 |
|---|---|
| 1. 레이어×헤드 히트맵 | 모든 prefix 조건이 레이어 1부터 플로어 위. 효과는 8개 KV 헤드 전체에 퍼져 있고 레이어 1–8에서 가장 큼. 특정 헤드가 두드러지지 않음. |
| 2. 레이어 곡선 | L2 기준 V·잔차 최대 약 1.5–1.8배, K는 약 1.6–2.9배(레이어 3 부근). 마지막 레이어에서는 약 1.1–1.4배. H+/H−가 P1/P2보다 높고 P2가 플로어에 가장 가까움. pre-RoPE K와 post-RoPE K는 구분되지 않음(모든 조건에서 위치가 같아 RoPE 효과가 상쇄). |
| 3. 본문 내 감쇠 | 거리/플로어가 본문 위치가 뒤로 갈수록 오히려 증가. 246 토큰 안에서 prefix 효과가 희석되지 않음(필러 간 차이가 지시문 차이보다 빨리 사라짐). P1 방향 사영의 절대값은 위치에 따라 감소. |
| 4. 방향 벡터 | mean(조건 − F)의 지문 간 코사인은 P1/P2에서 약 0.85–0.95로 높지만, 의미 없는 F1−F2 방향(null)도 약 0.7–0.9. H+, H−, P2도 P1 방향에 P1 못지않게 사영됨. 페르소나 고유 방향이라기보다 "지시문이 있다 vs 필러"라는 일반적 오프셋으로 보임. |
| 5. 선형 프로브 (F/P1/P2, 지문 단위 leave-one-out, 우연 수준 0.33) | 레이어 0은 정확히 우연 수준. 레이어 11–17에서 최고: 잔차 0.82, K 0.75, V 0.73. 잔차가 조건 정보를 가장 깨끗하게 담음. |
| 6. 행동 연결 (다음 토큰 KL) | assistant 턴 시작 위치에서는 모든 조건에서 `<think>` 확률이 0.9993이라 KL≈0으로 무의미. 본문 마지막 토큰에서는 F1 대비 KL이 H+/H−/P1/P2 0.09–0.15 nats, F2(플로어) 0.034 nats → KV 차이가 출력에 약 3–4배 플로어 수준으로 도달. |

## 4. 해석
- prefix는 같은 본문 토큰의 K/V와 잔차를 실제로 바꾸며, 그 차이는 출력 분포까지 전달된다.
- 다만 크기는 노이즈 플로어의 약 1.5–3배로 크지 않고, 페르소나 고유의 신호라고 말할 근거는 아직 없다. 힌트 조건이 더 크게 움직인다.
- 조건을 구분하는 선형 정보는 중간 레이어, 특히 잔차 스트림에 가장 많다.
