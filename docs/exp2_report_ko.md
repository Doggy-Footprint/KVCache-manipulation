# 실험 2 결과 보고서: 대화 주제 전환의 KV 캐시 신호

## 1. 설정
- 모델: Qwen3-0.6B (bf16, MPS, eager attention). 파이프라인 검증용이며 4B 결과는 없음.
- 데이터: `data/exp2_dialogues.jsonl` 11개 대화. 축구(A) 6턴쌍 뒤에 다음 조건:
  - 쌍: 축구→야구(near), 축구→양자역학(far)
  - S1 선언+전환 / S2 선언 없는 급전환 / S3 선언만 하고 축구 계속 / S5 점진 이동(공의 회전·스카우팅 데이터 등 중간 3턴쌍 → B) / S6 A→B(4턴쌍)→A 복귀 / S4 축구만 (대조군, 1개를 두 쌍이 공유)
  - S2/S3/S5/S6은 기존 S1·S4 턴을 재조합해 새로 작성. 턴 0–11(토큰 0–280)은 모든 대화에서 토큰 단위로 동일.
- 프로브 학습용 텍스트: `data/exp2_probe_texts.jsonl` (축구·야구·양자 각 12문장, 대화와 문장 중복 없음).
- 노이즈 플로어: 주제 전환이 없는 S4. M1은 S4 인접 교환(exchange=user+assistant 한 쌍) 거리의 평균·표준편차, M2는 같은 턴 위치의 S4 값과의 차이, M5는 S4에서 변화점이 0개가 되는 최소 penalty.
- 코사인 계산 전 레이어별 전체 content 토큰 평균을 뺌(이방성 제거). 템플릿 토큰은 제외.

## 3. 해석
- **선언 vs 내용 (S1 vs S3):** 표현 기반 지표(M5 변화점, M4 일부)는 선언에서 먼저 꺾인다. 선언 턴은 문체가 크게 달라서("let's change the subject") near 쌍에서는 변화점이 선언에서만 잡힌다. 반면 attention mass(M2)는 실제 내용이 바뀌었을 때만 줄었다(far에서 S1≈S2≈S5 ≪ S3). KV 캐시만으로 계산할 수 있는 M2가 "선언"과 "실제 전환"을 가장 잘 분리했다.
- **표현/레이어:** 프로브와 변화점 모두 후반 레이어(22–27)의 K(pre/post)·잔차에서 가장 선명했다. V는 프로브에서는 비슷하지만 PELT에서는 덜 안정적이었다. pre-RoPE K와 post-RoPE K는 대체로 같은 결과였다.
- **주제 거리:** far(양자)가 near(야구)보다 모든 지표에서 크게 나타났다(M1 하락 폭, M2 감소 −0.08 vs −0.025, M3 군집 분리, M5 검출). 쌍이 2개뿐이라 상관이 아닌 순서 관계만 말할 수 있다.
- 인접 거리(M1)는 계획이 기대한 "경계 스파이크"가 아니라 전환 후 구간의 응집도 변화로 나타났다. 교환 단위 지표의 노이즈가 커서 단일 경계를 검출하기에는 약하다.

## 4. 한계 및 이탈 사항
- 쌍 2개 × 조건 5개 + 대조군 1개, 대화당 1개씩이라 통계 검정이 불가능함. 모든 수치는 단일 표본이다.
- 노이즈 플로어가 S4 대화 하나에서 나온다. PELT penalty도 이 S4에 맞춰 정했기 때문에 S4의 오검출 0건은 정의상 보장된 결과다.
- `extract.py`가 저장하는 `attn_mass.pre_shift`는 조건마다 끝점이 달라서 사용하지 않았다. 노트북에서 모델을 다시 돌려 모든 대화에 같은 A구간(토큰 1–280)으로 다시 계산했다. 프로브 텍스트의 활성도 노트북에서 직접 추출했다.
- M1의 이벤트 후 토큰 창은 선언(짧은 문장)과 내용을 섞는다. S5의 "중간 단계"는 주관적으로 작성한 것이다.
- 미수행: 4B 모델, 대화 규모 확대, 주제쌍 추가.
