# Qwen3-4B 파일럿 실험 기록 (2026-11-05)

실험 1(prefix가 본문 KV에 남기는 흔적)과 실험 2(대화 주제 전환)를 Qwen3-4B-Instruct-2507로 처음 끝까지 돌린 기록이다. 0.6B 결과는 `docs/exp1_report_ko.md`, `docs/exp2_report_ko.md`에 있다.

## 1. 요약

- **실험 1 — 흔적은 있지만, 출력은 그 흔적을 거의 쓰지 않는다.**
  - prefix를 바꾸면 같은 본문 토큰의 K/V/잔차가 노이즈 플로어의 1.3–3.9배로 달라진다.
  - 본문 토큰만으로 페르소나/필러를 0.97 정확도로 구분한다(우연 수준 0.33).
  - 출력(다음 토큰 분포)에 대한 효과는 정답 힌트와 페르소나에서 prefix KV를 직접 읽어 생긴다. prefix 구간 KV를 옮기면 회복률이 0.83–1.00이고, 본문 KV를 옮기면 0 근처다.
- **오도 힌트만 예외다.** 효과의 대부분이 본문 KV에 실린다(본문 0.74–0.90, prefix 0.21–0.38). 0.6B(본문 0.15, prefix 0.92)와 반대다.
- **형식을 맞춘 설계 v2의 중립 내용 문장(N0, "The following passage is a news article.") 대조:**
  - 힌트의 효과는 N0와 비슷한 크기다. 다음 토큰 KL 중앙값은 H+ 0.079, H− 0.062, N0 0.100이다.
  - 페르소나는 N0보다 크다(P1 0.112, P2 0.281). 표현 거리에서도 P1/P2와 N0의 차이는 F1과 N0의 차이보다 1.5–1.7배 크다.
  - 따라서 이 데이터로는 "힌트의 의미"와 "내용 있는 문장이 하나 있다는 사실"을 구분하지 못한다.
- **실험 2 — 0.6B의 패턴이 4B에서 대부분 재현된다.** 실제 내용 전환은 A 구간 attention을 줄이고 선언만으로는 적게 줄며, far 쌍이 near 쌍보다 크다. 대화가 11개(조건당 1개)라 통계 검정은 불가능하다.
- **비용:** 4B 전체 파일럿(추출, 패칭 4종, 요약, 판정)은 H100 GPU 작업 1957초, 약 $2.15였다. 분석은 Modal CPU에서 했고 텐서는 내려받지 않았다.

### 실험 1 조건
| 조건 | 내용 |
|---|---|
| F1, F2 | 중립 필러 두 개. F1이 기준, F1 vs F2가 노이즈 플로어 |
| H+ / H− | 올바른 / 잘못된 주제 힌트 ("The following passage is about {topic}.") |
| P1 / P2 | 회의적 변호사 / 공감적 상담사 페르소나 |
| N0 (v2만) | 중립 내용 문장 "The following passage is a news article." |

- **설계 v1** (`data/exp1_prefixes.json`): 필러는 날씨/도서관에 관한 긴 문단을 prefix 길이에 맞춰 자른 것이고, H/P는 공통 패딩 문장 뒤에 지시문 한 문장이다. 필러와 지시문의 형식이 다르다.
- **설계 v2** (`data/exp1_prefixes_v2.json`): 모든 조건이 "공통 패딩 + 완결된 한 문장"이다. 필러도 한 문장이다("The weather today is mild." / "The library opens at nine."). 형식과 길이가 조건 간에 같다.
- H/P 문장 자체는 v1과 v2에서 같다.

| M5 변화점 (PELT, S4에서 0개가 되도록 penalty 설정) | far S2·S6: B onset과 복귀를 1–5토큰 오차로 검출. far S1: K 레이어 18이 선언(1토큰)과 B onset(4토큰)을 각각 검출. S3도 선언 지점(287)과 선언 교환 끝(331–333)에서 검출. S5는 두 쌍 모두 중간 단계 시작 부근(3–38토큰 오차)에서 검출하고 B onset은 놓침 | 같은 경향 |

## 6. 해석

1. **출력 효과는 prefix KV를 직접 읽어 생긴다(정답 힌트, 페르소나).** 본문 KV는 prefix에 따라 바뀌지만, 그 차이를 F1 본문에 옮겨도 출력이 거의 움직이지 않는다. 반대로 F1 본문에 기증자 prefix KV만 붙이면 기증자 출력이 거의 그대로 나온다.
   - 이는 prefix 없이 계산한 본문 KV를 재사용하는 캐시 기법(CacheBlend, 위치 무관 캐싱)에서 이 readout 기준 품질 손실이 작다는 뜻이다.
   - 오도 힌트에서는 손실이 크다(prefix만으로 0.21–0.38).
   - 위 두 캐시 연구는 아직 `refs/references.md`에 없다.
2. **K와 V는 함께 있어야 한다.** prefix의 K만 또는 V만 옮기면 회복률이 −0.45~+0.57로 낮다. 예외는 v2 P2/H+의 V만(0.46–0.51)이다.
3. **오도 힌트의 경로는 노이즈 대조(F2)와 비슷하다.** 둘 다 본문 레이어 17–19의 KV에 실린다. 가능한 해석은 두 가지다.
   - 오도 힌트는 본문을 힌트에 비추어 처리하게 만드는 간접 경로를 쓴다.
   - 오도 힌트의 출력 효과가 내용 없는 차이와 같은 성질이다.

   v2에서 H−의 KL 중앙값(0.062)이 N0(0.100)보다 작은 것은 두 번째 해석과 맞는다. 힌트 문구가 한 세트뿐이라 판정하지 못한다(가설).
4. **힌트의 "의미"는 분리되지 않았다.** v2에서 힌트의 표현 거리와 KL은 중립 내용 문장(N0)과 비슷하다. 힌트 방향의 지문 간 일관성도 null보다 낮다. 페르소나는 N0보다 크고 방향도 일관되어, 내용 특이적 성분이 있다는 증거가 힌트보다 강하다.
5. **실험 2의 0.6B 관찰이 4B에서 재현된다.** M2(KV 캐시만으로 계산 가능한 attention mass)가 선언과 실제 내용 전환을 가장 잘 구분한다는 결론이 두 모델에서 같다. 다만 각 수치는 대화 1개짜리다.

## 7. 한계

1. 단일 readout 위치(빈 think 블록 다음 토큰)와 greedy 16토큰 log-prob만 썼다.
2. 지문 30개는 모두 이 프로젝트에서 작성한 영어 보도문이다. 힌트·페르소나 문구는 각 한 세트다.
3. v2 F2 행은 KL 분모가 작아(중앙값 0.011) 회복률이 불안정하다. 전체 구간 sanity가 0.89에 그치는 것도 이 때문으로 보인다(가설: 배치 계산의 bf16 오차가 분모에 비해 크다).
4. 평균은 분모가 작은 행의 꼬리(최대 |r| 20)에 끌리므로 중앙값과 사분위를 주 지표로 썼다. 노트북이 출력하는 평균±표준편차와 값이 다르다.
5. 실험 2는 쌍 2개 × 조건 5개 + 대조 1개, 조건당 대화 1개다. M5의 penalty는 S4에 맞춰 정했으므로 S4 오검출 0건은 정의상 보장된다.
6. 실험 2 노트북은 M2와 M4에서 CPU bf16으로 모델을 다시 돌렸다. 추출(H100)과 커널이 다르다.
7. 파일럿 1회다. 같은 설정을 반복한 run은 없다. L40S 패칭 run(`20261105-182040`)은 같은 입력의 다른 GPU 재계산이다.

## 9. 예산 관점의 판단

GPU 비용은 병목이 아니다. 4B 실험 전체가 약 $2이다.

1. **실험 1은 4B에서 계속할 가치가 있다.** 남은 질문은 두 가지다.
   - 오도 힌트 경로의 정체
   - 힌트 효과가 중립 내용 문장(N0)과 구분되는가

   둘 다 같은 실험으로 답할 수 있다. 힌트 문구를 여러 세트로 늘리고, 정답/오도 힌트와 같은 형식의 N0 변형을 넣고, 지문을 100개로 늘린다. 현재 단가로 GPU 약 $7이다(30개당 $2.15에서 비례 추정).
2. **27B는 그 다음이다.** 27B는 64개 레이어 중 16개만 KV를 쓰는 하이브리드 구조라 비교 해석이 4B 결과 정리에 달려 있다. 먼저 배치 벤치 1회로 단가를 잰다. 파일럿 비용은 측정하지 않았다.
3. **실험 2는 GPU보다 데이터 설계가 병목이다.** 추출은 87초다. 주제 쌍과 조건당 대화 수를 늘리지 않으면 같은 일화 수준 결과가 반복된다.
